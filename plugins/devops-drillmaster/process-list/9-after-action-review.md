# 9. After-action review — Light

The project's link to `/devops-drillmaster:after-action-review`, which does the work. It serves every
measure in the objective.

## Input

- Field logs, debriefs, tracker times and sessions since the last review   ← must meet: drill master
  POLICIES §2–§4
- Checked: by the after-action review, 2.1–2.4
- Documented: the after-action report

## Steps

9.1 Run `/devops-drillmaster:after-action-review` on the project's rhythm, or when a debrief says it
    is due.

## Output

- An after-action report and experiments   ← must meet: drill master POLICIES §1, §5
- Checked: by the owner, change by change
- Documented: `.drillmaster/aar/<date>.md`, `.drillmaster/experiments.md`
