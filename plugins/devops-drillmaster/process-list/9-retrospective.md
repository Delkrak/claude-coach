# 9. Retrospective — Light

The project's link to `/devops-drillmaster:retrospective`, which does the work. It serves every
measure in the objective.

## Input

- Impediment logs, process and item summaries, tracker times and sessions since the last
  retrospective   ← must meet: drill master POLICIES §2–§4
- Checked: by the retrospective, 2.1–2.4
- Documented: the retrospective report

## Steps

9.1 Run `/devops-drillmaster:retrospective` on the project's rhythm, or when an item summary says it
    is due.

## Output

- A retrospective report and experiments   ← must meet: drill master POLICIES §1, §5
- Checked: by the owner, change by change
- Documented: `.drillmaster/retrospectives/<date>.md`, `.drillmaster/experiments.md`
